# Epic Fight Villager King

Minecraft 1.20.1 Forge と Epic Fight 向けの追加 MOD です。[指定された NameMC スキン](https://ja.namemc.com/skin/e480685ee529111a)を使った独立ボス「村人の王」を追加します。

## 必要な環境

- Minecraft 1.20.1
- Forge 47.4.4 以降の 1.20.1 対応版
- Epic Fight 20.14.17（Forge 1.20.1 版）
- ビルドには Java 17

## 召喚

プレイヤーごとに、通常の村人への直接攻撃を記録します。累計 20 回目の攻撃で、そのプレイヤーの近くに村人の王が出現します。ボスの生存中、ワールド内に二体目は召喚されません。ボスを倒すと全員の攻撃回数は 0 に戻ります。攻撃回数と召喚したボスの情報はワールドに保存されます。

動作確認用に `/summon villagerking:villager_king` でも出現させられます。

## 戦闘

体力 500、基本攻撃力 10、防具値の設定値 40、Epic Fight のスタンアーマー 20、継続する再生 III を持ちます。追跡時の移動速度は従来の 0.32 から 0.48 に上げ、1.5 倍の速度でプレイヤーへ詰めます。スタンアーマーは出現直後やワールド再読み込み直後から働き、短いスタンを大幅に軽減します。強い攻撃によるスタンは残ります。通常攻撃の攻撃力には装備中の武器の攻撃力が加わります。Minecraft 1.20.1 の防具値属性には上限があるため、実際の計算に使われる防具値と軽減率はゲーム側の上限に従います。

戦闘中は 30 秒ごとに、打ち刀、ネザライトグレートソード、ネザライトの槍・太刀・ロングソード・ダガー、グローブ、ネザライトの剣・斧、トライデントの間で武器を切り替えます。剣とダガーは選ばれるたびに 50% の確率で二刀流になり、グローブは常に両手に装備します。Epic Fight 20.14.17 のオフハンド属性更新で残留する誤った攻撃速度Modifierは、武器交換直前に村人の王側で除去し、複数回の武器切り替えによる重複Modifierクラッシュを回避します。

通常攻撃は各武器の Epic Fight プレイヤー用アニメーションを 3 コンボ分使用し、続いて対応する武器技のアニメーションを 6 回使用します。この順番を次の武器切り替えまで繰り返します。トライデントの技は Wrathful Lighting です。これらのアニメーションをボスの Epic Fight エンティティ連携から再生するため、プレイヤー専用のスキル操作をボスへ直接適用しません。

攻撃アニメーションは村人の王に対してのみ 2.25 倍速で再生します。Epic Fight 側に元からある個別の速度補正は保持したまま、その結果へ 2.25 倍を掛けます。連撃はアニメーション全体が完全にアイドルへ戻るまで待たず、Epic Fight が `CAN_BASIC_ATTACK` を再び許可する安全なコンボ受付点で次の攻撃へ接続します。攻撃判定中やリンク遷移中には次の攻撃で割り込まないため、モーション途中の不正なキャンセルを避けつつ戻り部分の待ち時間を短縮します。槍やダガーの追撃も維持します。通常攻撃はターゲットが3ブロック以内に入ってから開始し、それより遠い場合は攻撃せず追跡します。攻撃開始直前にはターゲットへ即座に正対するため、背後へ回り込まれた後も同じ方向へ空振りし続けません。

ターゲットが 12 ブロック以上離れると、どの武器でも跳躍して Epic Fight 本体の `Animations.METEOR_SLAM`（`biped/skill/greatsword_slam`）で急降下します。跳躍中はターゲットを追尾し、接近すると水平速度を落として真上を取り、急降下開始時にターゲットへ視線を合わせます。着地時は Meteor Slam 本来の攻撃コライダーを優先し、それが命中しなかった場合だけ半径 6 ブロックに `ATTACK_DAMAGE × 4` の衝撃ダメージを補完します。時間による再使用制限はなく、着地までは重複発動しません。30 秒の武器切り替えはその最中も優先されます。

## 討伐報酬

村人の王を倒すと、死亡地点に飲める「王の力のポーション」を 10 本落とします。飲むと力 V（増幅値 4）が 10 分間（12,000 tick）続きます。`doMobLoot` を `false` にしたワールドでは落ちません。

## ビルド

Linux/macOS では `./gradlew build`、Windows では `gradlew.bat build` を実行します。配布用 JAR は `build/libs/` に出力されます。JAR にはスキンを同梱しています。NeoForge や別の Minecraft バージョンには個別の移植が必要です。

GitHub Actions は Gradle ビルド、専用サーバー起動、JAR の成果物アップロードを実行します。

## アセット

スキンは[指定された NameMC のページ](https://ja.namemc.com/skin/e480685ee529111a)の PNG を同梱しています。Epic Fight のアニメーションはインストール済みの Epic Fight から参照し、この MOD に再配布しません。
